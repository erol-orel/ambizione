# BASEC submission checklist

Mechanics learned from BASEC 2026-00324; verify against the current BASEC forms.

- [ ] **Route settled** (`01-route-strategy.md`): DPO opinion in writing; jurisdictional inquiry
      filed if Route A/C — text ready in `05-clarification-competence-fr.md`. *This is the only
      step needed before the Ambizione deadline.*
- [ ] BASEC account with the applicant as **requérant**; project created under the CCER (Geneva).
- [ ] Synopsis (`02-protocol-synopsis-fr.md`) finalised with the custodians' names and periods.
- [ ] Data specification attached; **identical wording** to the HUG agreement drafts.
- [ ] Art. 34 justification (if Route B/C): impracticability of consent + interests balance.
- [ ] Security concept: UNIGE secure environment description `[[from the HPC/security team]]`.
- [ ] Sponsor declaration `[[UNIGE/ISG — per RGO]]`; PI CV (BASEC format).
- [ ] HUG internal approvals: the custodian's *accord de principe* letters double as the
      collaboration letters requested in the Ambizione emails — one ask, two uses.
- [ ] Fees `[[check current CCER tariff for data-reuse / clarification requests]]`.
- [ ] After submission: log the BASEC number in `05-review/applicant-facts.md` and cite it in
      any Ambizione correspondence as evidence the pathway is in motion.
