# Draft support letter — send this with the request

Send it as an editable document on your own draft, saying plainly that it is a draft to save them
time and that they should change anything they disagree with. This is normal practice and it is
what makes the difference between a letter arriving in October and not arriving at all.

**Three things the letter must do**, in order of importance to the referee:

1. Confirm the data exists, is accessible, and that they are willing to make it available.
2. Be specific enough to be credible — name the dataset, the period, the granularity.
3. Describe Dr Orel as the person leading the work, not as a participant in theirs.

## Note on wording

The last line matters more than it looks: **"en tant que responsable scientifique"** — leading the
project. If a letter describes him as contributing to the service's own research, it quietly
contradicts the independence argument the whole application rests on. Worth checking before it is
signed.
