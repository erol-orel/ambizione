**HEADSTART: Forecasting health-system crises from published evidence when local outcome data are scarce**

# 1. Summary

At the start of a health crisis, many useful inputs are already available. Weather and air-quality measurements, calendar effects, wastewater and public surveillance data can often be obtained from public feeds or established partners. The main gap is not usually a lack of these contextual data. It is the lack of localised, timely, reliable data for the emergency episode of interest. Historical local records may be extensive. However, they are unlikely to immediately show how the new episode affects cause-specific emergency demand. The model must be able to approximate and update that relationship as new outcome data become available.

HEADSTART asks whether published evidence from other settings and past events can improve forecasts before enough outcomes from the current episode are available, and whether the method can detect when that evidence is misleading. Published studies help identify plausible parameter values, relevant explanatory variables and their lags, suitable model forms, and outcome definitions and warning thresholds. A prior is a probability distribution for model parameters before it is updated with outcomes from the current episode. It represents uncertainty rather than treating a published estimate as exact. HEADSTART will extract this information, measure extraction error and assess how relevant each finding is to Geneva. The main focus is on comparing an evidence-informed strategy to a reference strategy. Both employ the same available context feeds, previous local outcomes, and the outcomes observed so far in the current episode. Only the evidence-informed strategy uses information extracted from published studies to refine its parameter distributions and model choices.

The work has four linked parts. In the first, I will benchmark automated extraction against an independently adjudicated sample and analyse how extraction errors affect the uncertainty of the model inputs. I will then build a model that forecasts the target quantity and expresses it as ordered levels of pressure on the health system, with the number of levels and their thresholds taken first from the evidence and fixed before any test. I will replay past events using only the information available at the time of the forecast, and compare the two strategies. I will evaluate whether differences in forecast quality would influence operational decisions. Both strategies receive the same weather, air-quality, calendar and surveillance data, and make use of the same local historical outcomes. Prior to evaluating forecast performance, candidate models are chosen using the same criteria for both strategies.

The Geneva tests cover three types of crisis with different causes. The main test is based on respiratory epidemics, for which published evidence is comparatively abundant. The second test, run only if the first succeeds, is based on heat-related demand. The third, in year four, is based on legionellosis and uses a linked case-environment dataset to test case-incidence forecasting, outside the emergency-demand comparison. Before clinical data are analysed, the methods will be validated on open Swiss series and released as a public benchmark. If published evidence improves forecasts, the project will show when and by how much. If it has no benefit or causes harm, the result will define where it should not be used. For validated demand-based applications that the services authorise, forecasts will run in a daily observation-mode dashboard and be scored against outcomes as they arrive. The dashboard will not direct clinical care.

I trained as an econometrician, at the junction of statistics, mathematics and machine learning, and spent fifteen years in quantitative finance working on rare-event risk, regime changes and stress testing, and I am a certified Financial Risk Manager. A doctorate in biomedical sciences at Geneva brought these methods to public health. I conceived and built LiteRev with Aziza Merzouki in Olivia Keiser's group and extended it into LiteRev-Evidence, the prototype for structured evidence extraction and model comparison, and through GESICA I work daily with Geneva's emergency and surveillance data. HEADSTART builds on this work to test a distinct question, in a programme I will lead.
